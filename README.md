# Claude Limits

**Оставшиеся лимиты Claude — прямо в строке меню macOS.**

macOS 13+ · Swift / AppKit · версия 1.0.2 · интерфейс на русском

Значок Claude и три показателя: **F · O · 5**. Откройте меню, чтобы увидеть
проценты, время сброса и последнее обновление. Отдельного окна и значка в Dock нет.

## Что означают F, O и 5

| Метка | Показатель |
| --- | --- |
| **F** | Остаток недельного лимита Fable, если сервис передаёт это окно |
| **O** | Остаток недельного лимита Opus; при отсутствии отдельного окна — общей недели |
| **5** | Остаток общего пятичасового лимита |

Если для `O` используется общая неделя, меню явно пишет **«общая неделя, включая
Opus»**. Окна не складываются: свободный пятичасовой лимит не отменяет
ограничение недельного окна.

Проценты показывают **остаток**, а не расход: `100 − utilization`, с округлением
вниз. Неизвестные, устаревшие или недоступные значения обозначаются `—`.

## Возможности

- Автоматическое обновление примерно раз в **120 секунд** при нормальной работе.
- Проценты и время сброса каждого окна в часовом поясе macOS.
- Ручное обновление и переход на страницу лимитов Claude.
- Вход через штатный Claude Code.
- Запуск при входе в macOS, включая вход после перезагрузки.
- Одноцветный значок, адаптирующийся к светлой и тёмной строке меню.
- Обработка ошибок и ограничения частоты запросов без отображения выдуманных процентов.

## Установка через npm

npm-пакет содержит исходники и команду сборки нативного приложения. Для этой
команды нужны **macOS 13+, Node.js 20+ и Swift 5.9+ из Xcode/Command Line Tools**.

```sh
# Собрать и скопировать приложение в ~/Applications
npx claude-limits-macos install

# Или только собрать в ./dist
npx claude-limits-macos build
```

После установки откройте `.app` вручную из `~/Applications`. При обычном
`npm install` ничего не собирается и не запускается: в пакете нет install hooks.
Команда не включает автозапуск, не устанавливает системный фильтр и не меняет
сетевые настройки. Существующая копия приложения не перезаписывается: перед
обновлением завершите её и переместите в другое место.

[Пакет на npm](https://www.npmjs.com/package/claude-limits-macos) ·
`npx claude-limits-macos --help`

## Собрать и установить

Нужны macOS 13+, Swift 5.9+ из Xcode или совместимых Command Line Tools и
установленный [Claude Code](https://code.claude.com/docs/en/setup).
Сторонних Swift-пакетов нет.

```sh
git clone https://github.com/sergekostenchuk/claude-limits.git
cd claude-limits
./build-app.sh
open dist
```

Перенесите `Claude Limits.app` из папки `dist` в `~/Applications` или
`/Applications`, затем откройте его. Для обновления сначала завершите старую
копию через меню, затем замените приложение.

Скрипт собирает `.app` для архитектуры текущего Mac и подписывает его ad-hoc.
Локально проверено на Apple Silicon. Developer ID и нотариализация в этой
версии не настроены. Скрипт ничего не устанавливает и не включает автозапуск.

## Первый запуск

1. Войдите в Claude Code: команда `claude auth login` или пункт
   **«Войти в Claude Code…»** в меню приложения.
2. Если macOS требует доступ к связке ключей, выберите
   **«Разрешить чтение авторизации…»** и подтвердите системный запрос.
3. Нажмите **«Обновить сейчас»**.
4. При необходимости включите **«Запускать при входе»**. Отключить это можно
   в том же меню или в системных настройках объектов входа.

Если Claude Code уже авторизован и связка ключей доступна, повторный вход
не требуется. Пункт входа открывает Terminal и запускает собственную команду
авторизации Claude Code; приложение не принимает пароль аккаунта.

## Данные и авторизация

Источник — `https://api.anthropic.com/api/oauth/usage`. Это **внутренний endpoint**,
его формат и доступность могут меняться. Нужен аккаунт Claude Code, которому
доступен этот источник; обычный API-ключ Anthropic не заменяет OAuth-вход.

Приложение читает существующую запись `Claude Code-credentials` в связке ключей.
Только если записи нет, используется `~/.claude/.credentials.json`. Отказ или
блокировка связки ключей не приводят к чтению запасного файла.

OAuth-токен отправляется только в запросе к endpoint Anthropic.
HTTP-перенаправления запрещены. Токены не встроены в приложение, не сохраняются
им и не записываются в логи. Проценты хранятся в памяти. Аналитики и стороннего
сервера у приложения нет.

Приложение не вызывает модели для генерации, не меняет авторизацию Claude Code
и не обновляет refresh token самостоятельно. Если токен истёк, свежую
авторизацию должен предоставить Claude Code.

## Если вместо процентов отображается «—»

| Сообщение или ситуация | Что делать |
| --- | --- |
| «Нужно войти в Claude Code» | Повторить штатный вход и обновить показатели |
| «Нужно разрешить чтение авторизации» | Использовать соответствующий пункт меню |
| Нет отдельного показателя модели | Это окно не передано сервисом; приложение не подставляет 100% |
| Данные устарели | Проверить связь и дождаться обновления |
| HTTP 429 | Дождаться срока `Retry-After`; ручное обновление его не обходит |
| Изменился формат ответа | Проверить Issues или сообщить об ошибке без токенов и личных данных |

После ошибки, окончания окна или пяти минут без свежих данных числа в строке
меню заменяются на `—`. Если старый снимок остаётся в меню, он явно помечается.
При обычных ошибках задержка повторов возрастает до 15 минут; при HTTP 429
она может быть больше — в соответствии с ответом сервиса.

## Разработка и диагностика

```sh
swift test --disable-sandbox --scratch-path /tmp/claude-limits-tests
./build-app.sh
```

Команды npm-обёртки проверяются отдельно: `npm test`. У них нет внешних
зависимостей.

15 unit-тестов проверяют проценты, модельные и общие окна, отсутствующие и ложные
поля, даты сброса, устаревание, авторизацию, задержки повторов и HTTP-запросы.
Тесты используют искусственные данные и не требуют доступа к вашему аккаунту.

Локальная диагностика без чтения авторизации и запросов сети:

```sh
"dist/Claude Limits.app/Contents/MacOS/ClaudeLimits" --diagnose --local-only
```

`--diagnose` без `--local-only` выполняет запрос лимитов с вашей авторизацией.
`--debug` включает OSLog `com.kostenchuksergey.ClaudeLimits/usage`: HTTP-коды,
без токенов и тел ответов.

Ошибки и предложения можно отправлять через Issues, изменения — через Pull
Request. Изменения формата лимитов сопровождайте обезличенным тестовым примером.
